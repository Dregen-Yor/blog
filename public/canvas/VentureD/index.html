03 / 核心能力

Difference Detection → User-controlled Reminder → Focused Retry → Learn

01 / DETECTION

识别关键动作差异

对比用户与标准动作，找到置信度最高、最值得优先修正的一个差异。

02 / CONTROL

提醒机制由用户设置

用户选择中途提醒、动作后复盘或自适应模式，并决定语音、屏幕或机器人手势提示。

03 / LEARNING

反馈服务于下一次改进

每次只给出一个可执行建议，针对性复测，并记录长期能力变化与提示依赖。

04 / 用户痛点

看懂标准动作，不等于知道自己错在哪里。

用户缺的不是更多教学内容，而是针对自己的动作反馈：哪里不同、应该先改什么。

视频课程展示“老师怎么做”，但无法解释“我为什么做不像”。
摄像头 + 大屏能 Show Me，但用户仍需从复杂画面中自己抽取身体意义。
AI 姿态识别擅长 Detection，却常把身体学习压缩成分数、角度和红框。
真人教练诊断和解释最强，但成本高、时间有限，课后反馈无法持续。
Mirror Lean 不替代真人教练，而是把教练的方法延伸到每一次自主训练。

07 / 为什么是机器人

屏幕只能展示动作，
机器人让关键差异在真实空间中被看见。

机器人通过视线、指向、语音和节奏提示，在用户选择的时机把注意力带到一个关键差异，帮助用户立即调整并重新尝试。

Camera + Screen

  • 成本低、部署成熟、适合骨架与数据展示
  • 主要等待用户主动查看和理解反馈
  • 提醒容易变成通知或训练后的报告

Embodied Companion

  • 用视线、指向、语音和节奏提示聚焦一个关键差异
  • 在共享空间中建立自然的轮流练习与反馈关系
  • 记住用户偏好的提醒时机，并随能力提升减少打扰
核心待验证问题：由用户控制的具身提醒，是否比屏幕提示带来更高的理解、训练坚持和自主修正率？

机器人不复现错误动作，也不替用户决定；它负责发现差异、询问偏好、适时提醒和记录成长。

09 / 成长记忆

Memory 不是保存录像，
而是建立“这个人如何学会”的模型。

动作模式哪些关节关系、节奏和代偿问题反复出现。
提示阶梯用户需要注意线索、语言提示、慢放，还是完整示范。
能力边界用户当前可稳定完成的幅度、速度与动作复杂度。
学习保持隔天、隔周是否仍能完成，而不是只看单次分数。
辅助递减能力保持时逐步减少提示，让用户最终不依赖机器人。
